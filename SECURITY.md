# Security Policy

## Supported Versions

PAT-Noxim is a research simulator. Security fixes are applied only to the
latest version on the `master` branch. Older revisions are not maintained.

| Version           | Supported          |
| ----------------- | ------------------ |
| latest (`master`) | :white_check_mark: |
| older             | :x:                |

## Reporting a Vulnerability

If you discover a security issue (for example, a crash, memory-safety bug,
or unsafe file/command handling in the simulator or its build scripts),
please report it privately rather than opening a public issue.

- **Email:** [a.norollah.official-at-gmail.com](mailto:a.norollah.official@gmail.com)
- Please include:
  - A description of the issue and its potential impact.
  - Steps to reproduce (configuration file, command line, and inputs used).
  - The platform, compiler, and SystemC version you were running.

You can expect an acknowledgement within a reasonable time frame. Once the
issue is confirmed, a fix will be prepared and released on `master`, and
credit will be given to the reporter unless anonymity is requested.

Please do not publicly disclose the details until a fix has been made
available.
